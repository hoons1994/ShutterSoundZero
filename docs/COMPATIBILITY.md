# 호환성 정보 (Compatibility)

Shutter Sound Zero는 삼성 갤럭시 기기에서 카메라 셔터음 동작을 제어하기 위해 Android 시스템 설정과 무선 디버깅 기능을 사용합니다.

기기 모델, Android 버전, One UI 버전, 보안 패치 및 삼성의 시스템 설정 변경에 따라 동작 차이가 발생할 수 있으므로, 이 문서는 실제 테스트 결과를 기준으로 호환성을 기록합니다.

> **중요:** 아래 표에 없는 기기가 반드시 비호환이라는 뜻은 아닙니다. 아직 테스트 결과가 등록되지 않았을 수 있습니다.

---

## 지원 기준

현재 프로젝트의 기본 지원 범위는 다음과 같습니다.

- 제조사: Samsung Galaxy
- Android: Android 11 이상
- 프로젝트 `minSdk`: 30
- 프로젝트 `targetSdk`: 37
- 필수 기능: 개발자 옵션 및 무선 디버깅 사용 가능
- 주요 동작: 삼성 CSC 카메라 셔터음 설정 변경

다만 Android 버전이 지원 범위에 포함되더라도, 삼성 펌웨어 또는 One UI 변경에 따라 일부 기능이 제한될 수 있습니다.

## 테스트 항목

호환성 확인 시 다음 항목을 기준으로 테스트합니다.

### 1. 무선 디버깅 페어링

- 앱에서 무선 디버깅 설정 화면으로 정상 이동하는지
- 6자리 페어링 코드 입력 알림이 정상적으로 표시되는지
- 기기 내부에서 ADB 페어링이 정상 완료되는지
- 페어링 후 무선 디버깅을 꺼도 적용된 설정이 유지되는지

### 2. 셔터음 설정

- 앱에서 카메라 셔터음 설정 변경이 정상적으로 적용되는지
- 벨소리 모드에서 기존 셔터음이 정상적으로 유지되는지
- 진동 또는 무음 모드에서 셔터음이 비활성화되는지
- 설정을 다시 원래 상태로 복원할 수 있는지

### 3. Quick Settings 타일

- 빠른 설정 패널에 타일을 추가할 수 있는지
- 타일을 통해 설정을 정상적으로 켜고 끌 수 있는지
- 앱 상태와 타일 상태가 일치하는지

### 4. 재부팅 및 업데이트 이후 동작

- 기기 재부팅 후 설정이 정상적으로 유지 또는 복원되는지
- 앱 업데이트 후 기존 설정이 유지되는지
- One UI 또는 Android 업데이트 이후에도 정상적으로 동작하는지

## 호환성에 영향을 줄 수 있는 요소

Shutter Sound Zero의 핵심 기능은 Android 및 삼성 시스템 동작에 의존하므로 다음 변경의 영향을 받을 수 있습니다.

- Android의 무선 디버깅 및 로컬 네트워크 정책 변경
- One UI의 설정 앱 구성 변경
- 삼성 CSC 관련 시스템 설정 변경
- `WRITE_SECURE_SETTINGS` 동작 또는 권한 정책 변경
- 부팅 완료 브로드캐스트 처리 방식 변경
- 백그라운드 및 Foreground Service 정책 변경
- 제조사 펌웨어의 카메라 셔터음 정책 변경

특히 대규모 Android 또는 One UI 업데이트 직후에는 기존에 정상 동작하던 기기에서도 재검증이 필요할 수 있습니다.

## 버전별 재검증 원칙

다음 변경이 포함된 릴리즈에서는 주요 기기의 호환성을 다시 확인하는 것을 권장합니다.

- `targetSdk` 변경
- Android 메이저 버전 대응
- One UI 메이저 버전 대응
- ADB 또는 무선 페어링 라이브러리 변경
- BouncyCastle / Conscrypt 등 암호화 계층 변경
- CSC 설정 처리 로직 변경
- 부팅 후 자동 복원 로직 변경

단순 UI 변경이나 문서 수정만 포함된 릴리즈는 별도의 전체 호환성 재검증이 필요하지 않습니다.

## 알려진 제한 사항

- 삼성 갤럭시 이외 제조사의 기기는 공식 지원 대상이 아닙니다.
- 삼성의 시스템 정책 변경에 따라 기존 방식이 향후 동작하지 않을 가능성이 있습니다.
- 국가, 통신사, CSC 구성 또는 펌웨어에 따라 동일 모델에서도 동작 차이가 발생할 수 있습니다.
- 이 문서의 호환성 정보는 실제 테스트 시점의 소프트웨어 환경을 기준으로 하며, 이후 업데이트까지 영구적인 동작을 보장하지 않습니다.
