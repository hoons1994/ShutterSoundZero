# ShutterSoundZero

[한국어](README.md) · [English](README.en.md)

ShutterSoundZeroは、Galaxyの標準カメラで**シャッター音を強制する設定（CSC）**を変更するアプリです。この設定が端末に反映されると、カメラは端末のサウンドモードに従います。サウンドモードが「サウンド」のときは通常、シャッター音が鳴りますが、システム音量やカメラアプリによっても変わります。設定後は標準カメラで実際に撮影して確かめてください。

## 使用環境とインストール

- 対象はAndroid 11以降のGalaxyです。初期設定にはWi-Fi、開発者向けオプション、ワイヤレスデバッグを使います。PCやUSBケーブル、別のADBアプリは不要です。
- 日本語UIは端末の言語設定に従います。標準の表示言語は韓国語です。日本向け販売モデルでの動作や、特定のファームウェアでシャッター音を消せることは確認していません。
- 正式版のAPKは[GitHub Releases](https://github.com/hoons1994/ShutterSoundZero/releases/latest)からダウンロードできます。このREADMEは開発中のソースに対応しています。公開済みのAPKで利用できる言語・機能は、そのリリースの説明をご確認ください。

アプリだけ言語を変えたいときは、「設定」→「アプリの表示」→「言語」を開いてください。初期設定の「システム設定に合わせる」のほか、「한국어」「日本語」「English」を選べます。

## 初期設定

1. Wi-Fiに接続してアプリを開きます。通知からペア設定コードを入力するため、Android 13以降では通知を許可してください。Android 17以降でローカルネットワークへのアクセスを求められたら許可します。
2. 開発者向けオプションが無効な場合は、「端末情報を開く」からソフトウェア情報を開き、ビルド番号を7回タップしてください。端末のPINなどを求められる場合があります。
3. ホームの「初期設定を開始」をタップし、端末の開発者向けオプションでワイヤレスデバッグをオンにします。コードを使ってペア設定する画面を開き、そのままにしてください。
4. ShutterSoundZeroの通知で「コードを入力」をタップし、端末に表示された6桁の数字を入力します。接続できると、アプリが必要な権限を取得し、シャッター音の強制設定を解除します。設定後、アプリはワイヤレスデバッグをオフにしようとします。オンのままなら手動でオフにしてください。

## 再適用と復元

ソフトウェア更新などでカメラ設定だけが初期状態に戻ったときは、ワイヤレスデバッグをオンにして、アプリの「設定」→「カメラ設定」→「シャッター音の設定を再適用」を選びます。元の設定に戻したいときは、同じ画面で「シャッター音の設定を元に戻す」を選び、復元を確認してください。

**端末のサイレント・バイブは別の設定です。** カメラを使っている間だけ電話や通知の音を切り替えたいときは、「カメラ使用中のサウンドモード」で「サイレント」または「バイブ」を選び、「ルーチンを追加」をタップします。取り込むルーチンの名前は、それぞれ「カメラ（消音）」「カメラ（バイブ）」です。Galaxy側の画面で、カメラの起動条件、サウンドモード、終了時に元の設定へ戻ることを確認して保存してください。両方を保存した場合は片方だけを有効にします。項目名や配置はOne UIのバージョンによって異なります。ルーチンや端末設定の画面には、それぞれのアプリで設定されている言語が使われます。[Galaxy公式サポート：モードとルーチンの使い方](https://www.samsung.com/jp/support/mobile-devices/how-to-set-up-and-use-the-bixby-routines-feature-on-your-galaxy-phone/)

## うまくいかないとき

- **コードを入力する通知が出ない** — 端末の設定でアプリの通知と「初期設定のご案内」チャンネルが有効か確認してください。コードが変わった場合は、今表示されている数字を使います。
- **ワイヤレスデバッグをオンにできない** — Wi-Fi接続と端末のセキュリティ設定を確認してください。自動ブロッカーを一時的にオフにした場合は、作業後にワイヤレスデバッグをオフにし、自動ブロッカーを再びオンにしてください。
- **コードの認証後に適用に失敗する** — Wi-Fiとワイヤレスデバッグをオンにしたまま、通知の「接続と設定を再試行」を選びます。以前のペア設定が無効な場合は、エラー画面の「6桁のコードで再接続」から新しいコードで接続してください。
- **認証情報のエラーが続く** — まず端末の日時を確認してください。再接続しても失敗する場合は、設定の「接続情報をリセット」から接続キーを作り直せます。新しいコードでのペア設定が必要です。
- **設定を適用しても音が鳴る** — 設定値の確認と、実際の撮影音の確認は別です。端末のサウンドモードとシステム音量を確認し、標準カメラでお試しください。問題が続く場合は、アプリの「問題を報告」から診断情報を確認し、直前の操作を添えてください。ペア設定コードや個人情報は記入しないでください。
